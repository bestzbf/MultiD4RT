# 新验证面板下的学习率试验（2026-10-08）

**已部署条件策略：55,500 步在扩大后的固定验证面板上稳定通过后，将两组 LR 用 100 步提高到断点实际 LR 的 1.5 倍，并在 56,000 步复核。** 部署时仍在训练当前 55k→55.5k 段，升 LR 尚未触发。这是一次有限区间试验，尚不能说明提高后的 LR 更优。

## 历史学习率核对

`lr_history.json` 记录实际训练日志、控制器决策和恢复计划：

- 48k 的首次候选因原两场景 BlendedMVS depth 比值 1.29848 触发回退，从 46k 完整断点以主 LR 约 `5e-7` 重试，原计划约为 `1e-6`。通过后的减半计划由后续训练继承。
- 最近的 55.5k 失败重试曾降到约 `2.365e-7` 和 `1.183e-7`，但这些候选未通过、未被当前四卡训练继承。
- 当前四卡训练从已接受的 55k 父模型恢复，主 LR 仍约 `4.7e-7`，backbone 约 `4.7e-8`。其原计划为 cosine，起点 46k、终点 100k，base LR 为 `[4.9981531e-8, 4.9981531e-7]`。

旧面板确实参与过 LR 减半及多次重试；但尚未用新面板重算 48k 首次候选，不能将那次拒绝断言为误判。[新面板审计](../blended_validation_migration_20261008/README.md)已证明，之前一个 55.5k replay 候选在扩大范围、统一参考基线后不再触发原回退门槛。

## 触发、验收及恢复

| 阶段 | 实际规则 |
| --- | --- |
| 55.5k 触发 | 第零次验证通过；相对上一份及最佳参考，24 项误差比的几何均值分别 ≤1.02，最大单项比分别 ≤1.10 |
| 提高 LR | 从完整 55.5k checkpoint 恢复；两组 LR 的目标值为各自当前值 ×1.5；100 步线性 warmup，从原 LR 附近开始 |
| 预计峰值 | 主 LR 约 `7.0523e-7`；backbone 约 `7.0523e-8`；实际按 55.5k 保存的 optimizer LR 计算 |
| 衰减终点 | 新 cosine 阶段从 55.5k 延续至 100k，最低倍率 0.2；之后续训继承该计划 |
| 56k 验收 | 通过原质量门槛，并且对 55.5k 的综合误差比 ≤1、最大单项比 ≤1.10 |
| 试验未达标 | 从同一完整 55.5k 断点恢复其原 LR 计划，重跑这 500 步；不会先减半 |
| 原 LR 重试也失败 | 再以原断点 LR ×0.5 进行剩余一次恢复；沿用原有最多两次重试预算 |

触发条件不满足时记为 `skipped` 并沿用原计划。成功或回退结束后记为 `completed`，记录实际采用的 checkpoint、retry 和 LR plan；56k 以后的普通阶段不会再次启动本试验。

验证继续使用 26 个 BlendedMVS 场景、52 个固定组合，加上原 Hypersim/Taskonomy 后共 60 个静态组合；45k/53k/55k 参考均已按同范围重算，当前最佳参考为 55k。其他 Kubric、原生动态、可变 C/T 和 Syn4D 验证继续运行。选模用原 24 项质量面板；Syn4D 仍单独记录报告。

这不是成功升 LR 与原 LR 的并行配对实验；只有试验未通过时才重跑原 LR。56k 的结果可判断该候选是否符合保留条件，不能独立归因训练收益，也不代表已找到最优 LR。
