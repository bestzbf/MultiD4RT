## 全池准入缺项修复

全量 29 个 V1 场景已完成解包，但首次全池审计被 `hallway` 的排除记录阻止。逐项核对确认：6 路相机缺少 tracking 索引及 shard，保留其他完整相机；另有 3 条序列的不同相机参考帧区间不重叠，在当前“所有相机共同 reference 时刻”的策略下不可采样。这 3 条并不代表 GT 错误，后续可单独验证按相机子集选时刻的策略。

[reviewed_exclusions.json](reviewed_exclusions.json) 明确记录这 9 项的路径、原因和核实结果。审计器现在支持严格匹配该清单：有新的排除、原因变化或原排除已消失都会再次失败。该清单只确认加载器原本排除的流/序列，不启用未知运动 GT，也不放宽几何检查阈值。

继续核对全池元数据时发现 8 个缺失物体网格，分别影响 cyber_bald、hallway、hospital、office_bald、village 中的 8 条序列。[upstream_missing_objects.json](upstream_missing_objects.json) 记录官方发布版本 `bb08d13faabc0649a4a938030025e9e2b32a6189` 中这 8 个文件均返回 `404 EntryNotFound`。明确清单新增独立的 `missing_objects` 项，允许现有加载器屏蔽这几个物体的未知运动，保留深度、其他物体及环境监督。新的缺失仍会失败，不能通过该清单伪造资源。新增反向传播测试确认：缺失物体保留深度和自时刻几何，不接受跨时刻运动或静态点监督，未知运动梯度为零。

[reviewed_pool_unit_tests.json](reviewed_pool_unit_tests.json) 记录服务器通过 28 项 Syn4D、扩池和准入相关测试，本地同样通过。
