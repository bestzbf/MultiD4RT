该场景是俯视道路、广场、植被和屋顶的航拍画面。已有[独立 GT 审计](../gt_integrity_20261008/README.md)检查了 H5 图像/深度、裁剪、内外参和最终归一化标签；C4/C8 平滑重叠区域跨视角深度在 2% 内的一致率分别为 98.04%/98.67%。其中可能遮挡的点单独统计，这不是全数据 GT 错误率；也不构成对未找到的原始 PFM 打包前处理的独立认证。

本次增加逐视角深度诊断，见 `depth_bias_diagnostics.jsonl`。C8 的有符号相对深度误差中位数从 53k 的 −0.793% 变成 55k 的 −1.332%，55.5k 为 −1.476%，显示整体趋向低估。不同视角的偏移不一致：例如 view 63 的平均偏差从 −1.881% 变为 −2.833%，而 view 39 从 +1.391% 变为 +1.555%。

仅作诊断地给整个片段拟合一个中位数深度倍率后，AbsRel 从 0.01031313 增至 0.01248378，仍存在退化；逐视角分别拟合倍率后，各视角残差大体稳定。这更支持视角之间的深度偏移/尺度一致性变差这一解释，尚不能确定其训练成因。倍率来自 GT，仅用于分析，正式指标和训练预测均未采用这种对齐。
