# GT 准确性与加载器独立复查（2026-10-08）

本次针对加入完整 Syn4D 后的验证退步，检查原始数据、相机/时间转换以及送入 loss 的标签。检查对象为 12 个 Syn4D 片段、BlendedMVS 的全部 4 个固定验证片段，以及退步的 Kubric C1T32 片段。前一轮 821 条序列的资源审计见 [完整池记录](../syn4d_20261008/README.md)。本次补充物理投影检查，避免仅凭“与官方读取器一致”判定标签正确。

**结论：抽查没有发现相机、帧序、单位或场景尺度的系统性错位；原始渲染/网格标签有少量边界不一致；加载器存在一处可见性边界错误，已修复。现有证据不足以把整体退步归因于坏 GT。**

Syn4D 使用 8 个固定 C2T4 验证片段，另外为 4 个 V1 场景加入 C1T16、步长 5 的片段。全源像素由生产加载器物化；float64 和投影诊断按每个 mesh 抽样最多 2,000 点，环境每个距离区间最多 5,000 点。训练仍采用原分辨率、全部有效像素监督，这些抽样仅用于独立审计。诊断假设使用原始相机和目标深度；目标深度缺失、出画面与可能遮挡均单独统计。

原始 compact face 标签与渲染深度并非严格落在同一个三角面上，官方恢复方法包含法向偏移。抽查也出现重心坐标越过三角形边界，不能仅凭这一现象判定轨迹错误。本次同时检查其跨时间/视角物理一致性，没有直接按重心阈值删除动态监督。参考 [官方恢复代码](https://huggingface.co/datasets/Syn4D/Syn4D/blob/main/code/visualizer/syn4d_track.py)。

可见性修复位于 `multicamera4rc/datasets/syn4d_dense.py`：之前用补边后的 H/W 判断是否出画面，落入 padding 的点会被视为缺少深度；现在记录每个观测的实际图像范围，并按整数像素中心的半像素边界判断。图内深度空洞继续保持未知。可变相机数量的 collate 同步补齐该元数据。回归测试覆盖图像右/下边缘、亚像素边缘和图内深度空洞。

`padding_comparison.json` 在 V1 和 Sim 各一个真实 C2T4 片段上对照旧代码：15 个几何/掩码/尺度张量逐项完全相同，旧的正可见性全部保留；补充 176,312 个出画面负标签，纠正 9,551 个边缘正标签。它会影响可见性监督，但没有改变这两个片段的 depth、trajectory 或 scene flow GT。`unit_tests.json` 记录最终代码通过 71 项测试。

`ddp_proof.json` 记录最终修复代码在 GPU4/5 上完成 7 次实际优化器更新、14 个样本，覆盖 V1 的 C1T16/C2T8/C4T4/C8T2 和 Sim 的 C1T16/C2T8/C4T4。两个 rank 都使用真实稠密 GT，loss 和梯度有限，没有跳过更新。该独立测试的 checkpoint 不用于正式恢复；正式混合训练从原 55k checkpoint 开始。

验证退步并非全部出现在完整池扩充之后。相同固定计划下，BlendedMVS depth AbsRel 为：53k 历史基线 **0.00726285**，55k 扩充前 **0.00897302**，第三轮 55.5k 候选 **0.00917689**。候选比 55k 增加 2.27%，比 53k 增加 26.35%，因此仍触发原有 25% 单项退步门槛。三次重试均保留，未降低验证门槛。混合训练的旧域遗忘/优化失衡是目前更符合证据的解释，尚未由受控消融确证。

恢复配置 `replay_mixture.json` 保留全部 25 个数据源、659 条 Syn4D 训练序列及原布局。仅将 BlendedMVS 从 3.6% 提到 8%，Kubric 从 25.2% 调到 20.8%；V1/Sim 各 5%，其他来源不变。`replay_config_proof.json` 验证配置只有指定权重和日志路径改变。恢复完整 55k checkpoint 的模型、Adam 和学习率计划，重置改变配比后的数据游标；目标仍为 100k，GPU4/5，每卡 BS1，全局 BS2。先训练 500 步再按原验证门槛判断能否继续。该调整是待验证的恢复实验，不能据此宣称效果已经改善。

`replay_training_health.json` 记录北京时间 **2026-10-08 10:23:43** 的正式训练快照：已更新至 **55,033** 步，33 次更新共 66 个样本，其中 V1 9 个、Sim 4 个、BlendedMVS 6 个。所有 loss 和梯度有限，未跳过优化器更新，坏样本日志为空。实际加载的数据计划包含全部 25 个来源，Syn4D V1/Sim 分别包含 455/204 条训练序列。运行代码固定为 `92380dc07fe67bc3a8918cac9e7e0bc221d4513a`；本目录后续文档提交不修改运行中的模型或训练标签。
